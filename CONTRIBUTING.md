# Contributing to Keypals

Keypals is a free typing game for kids, with no ads and no tracking. You're welcome to help: fix a bug,
improve a lesson, suggest a word list, or make something smoother on older computers.

## How

1. Fork the repository on GitHub, make your change on a branch, and open a pull request.
2. The first time, the CLA Assistant bot asks you to sign the [contributor agreement](CLA.md) by
   leaving a comment. That lets us use your work in the game.
3. Run `npm install`, `npm run dev` (http://127.0.0.1:5192) and `npm test` before you send it.

## What the licence allows

Keypals is **free and source-available**, not open source. Under the [licence](LICENSE)
(PolyForm Strict 1.0.0) you can read the code, run it yourself for any noncommercial purpose (home,
school, research) and send us improvements. You can't publish changed copies or your own version of
the game. The art, characters, voices and music are all rights reserved (see
[LICENSE-ART.md](LICENSE-ART.md)).

## Good first things

- A lesson that feels too hard or too easy: say which and why.
- Word lists and sentences for young typists.
- Anything that runs slowly on an older computer (note the computer and browser).
